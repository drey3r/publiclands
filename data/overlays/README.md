# Your overlay layers

Put `<id>.geojson` files here (a GeoJSON FeatureCollection in WGS84). Each one becomes a toggle in the map key. You can
add an optional `<id>.json` next to it with `title`, `color`, `attribution`, `description` and `visible`. See
`examples/overlays/` and the README section "Build your own layer".

This folder is empty in the public build.
